## 1. 目的与范围

验证范围 = 需求文档 v1.1 全部 v1 交付项。**四大安全/资金专项**（跨租户越权、资金三件套、订阅状态机、配额）为回归重点，任何里程碑合并均须通过对应专项；后续版本池内容不在本计划内。

## 2. 测试策略

### 2.1 分层与工具链

| 层 | 工具 | 范围 | 执行时机 |
|----|------|------|---------|
| 单元测试 | Vitest | Service 纯逻辑：状态机迁移表、幂等、配额计算、金额、切分函数、权限矩阵 | 每次提交（CI 门禁） |
| 接口测试 | Supertest + Nest 测试应用 | Controller 全路由：认证/权限/校验/业务正确性/越权矩阵 | 每次提交（CI 门禁） |
| 前端组件测试 | Vitest + Testing Library | 可选优先级：权限渲染 hook、请求层错误归一、SSE 封装（mock stream） | M2 起增量补充 |
| 端到端演练 | 手工 + 演示脚本 | 全链路：注册→…→订阅→通知；M6 演示路径（用户手册附录 10 分钟路径） | M6 |

### 2.2 测试环境与数据

- **独立测试库**：`DATABASE_URL_TEST` 指向独立 Postgres（含 pgvector），CI 中每次 `migrate deploy` 后跑测试。
- **数据清理**：e2e 套件按租户前缀造数 + afterAll 清理；单测 mock Prisma 或使用事务回滚，禁止依赖外部真实服务（SMTP → 捕获模式；LLM → mock SDK；R2 → MinIO 或 mock SDK；MockGateway 无外部依赖）。
- **确定性**：时间敏感用例（试用期到期、宽限期、回收站 30 天）注入 `FakeTimer` / 测试时钟，不 sleep。

### 2.3 里程碑质量门禁

| 里程碑 | 必须通过 | 准出标准 |
|--------|---------|---------|
| M1 | CI 全绿（lint/tsc/单测/build）、/health e2e | 骨架可跑 |
| M2 | **越权专项全量**、RBAC 拒绝用例、认证链路 e2e | 越权用例 0 失败（一票否决） |
| M3 | 回收站 30 天时钟用例、配额拦截、通知投递 | 软删恢复/清理正确 |
| M4 | RAG 隔离（B 租户不召回 A 的 chunk）、配额停用 | 用量口径一致 |
| M5 | **状态机全迁移矩阵**、**资金三件套演练**、账单/退款 | 状态机非法迁移 100% 拒绝 |
| M6 | 端到端演示路径 + 安全检查单 + 生产冒烟 | 全部 P0/P1 缺陷关闭 |

> 缺陷等级：P0 越权/资损/数据丢失；P1 核心功能不可用；P2 边界/体验；P3 优化。P0 当日修，上线前 P0/P1 清零。

## 3. 专项测试设计（安全与资金回归核心）

### 3.1 跨租户越权专项（TC-XAUTH）

**方法**：fixture 预置租户 A（owner_A/admin_A/member_A）与租户 B（owner_B），互相持有对方部分资源 ID。

| 编号 | 用例 | 预期 |
|------|------|------|
| TC-XAUTH-001 | B 的任一角色 token 读 A 的资源 `GET /resources/:aResourceId` | 403 或 404（不暴露存在性） |
| TC-XAUTH-002 | B 的 token 改/删 A 的资源 | 403/404，A 资源未变 |
| TC-XAUTH-003 | B 的 token 列 A 回收站 / 恢复 A 资源 | 403/404 |
| TC-XAUTH-004 | B 的 token 查 A 成员列表 / 邀请进 A | 403 |
| TC-XAUTH-005 | B 的 token 读 A 账单 / 订阅 / 发起 A 的退款 | 403（资金入口重点） |
| TC-XAUTH-006 | B 的 token 读 A 审计日志 / 租户设置 | 403 |
| TC-XAUTH-007 | B 用户 token + 伪造 `X-Tenant-Id: A`（无 membership） | 403 TENANT_MISMATCH |
| TC-XAUTH-008 | disabled 成员携带旧 token 访问 | 403（禁用即时生效） |
| TC-XAUTH-009 | removed 成员携带旧 token 访问 | 403 |
| TC-XAUTH-010 | B 提问 AI，知识库含 A 的同主题文档 | 回答与引用不含 A 的 chunk（RAG 隔离） |
| TC-XAUTH-011 | B 的 token 上传文件到 A 资源下 | 403 |
| TC-XAUTH-012 | SQL 注入载荷（name=`' OR '1'='1`、tenantId 参数注入） | 正常参数化处理，无越权返回 |
| TC-XAUTH-013 | 越权专项随每次 CI 回归（写死进 e2e 套件） | 持续绿灯 |

### 3.3 订阅状态机专项（TC-SUB）

全迁移矩阵：6 状态 × 6 目标 = 36 格。**仅下列合法迁移允许**，其余 30 条全部断言 409：

```
合法：none→trialing, none→active, trialing→active, trialing→expired,
     active→past_due, active→canceled, active→canceled(refund),
     past_due→active, past_due→expired, canceled→expired
```

| 编号 | 用例 | 预期 |
|------|------|------|
| TC-SUB-001~030 | 非法迁移矩阵逐条（active→trialing、expired→active、canceled→active…） | 409 + 订阅事件表无新行 + 告警（回跳类） |
| TC-SUB-031 | 发起试用 → trialing，权益即时 = Pro | 席位 20/AI 500/5GB |
| TC-SUB-032 | 试用到期未支付（时钟推进 14 天） | expired，权益回 Free，订阅事件含 expired 行 |
| TC-SUB-033 | 二次发起试用 | 409 TRIAL_USED |
| TC-SUB-034 | 模拟支付成功 | active，账单 paid，邮件+站内通知，权益联动 |
| TC-SUB-035 | 续费失败（mock 开关） | past_due + grace_deadline=+3d，权益保留 |
| TC-SUB-036 | 宽限期内成功续费 | active（past_due→active 唯一回活跃路径） |
| TC-SUB-037 | 宽限期满 | expired，回 Free，数据保留 |
| TC-SUB-038 | 期末取消 | canceled，current_period_end 前权益保留 → 过期后 expired |
| TC-SUB-039 | 立即取消 | canceled，即时降级 |
| TC-SUB-040 | 订阅期内退款 | canceled(refund)，即时降级，invoice→refunded，通知送达 |
| TC-SUB-041 | 权益快照 | 每次迁移后 GET /usage 的 limit 与新套餐一致（缓存失效正确） |

## 6. 缺陷与报告

- **流程**：GitHub Issues 管理，标签分级 P0–P3 + 模块标签；P0 当日响应，修复用例回归后关闭。
