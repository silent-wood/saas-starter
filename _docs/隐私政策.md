# SaaS Starter — 隐私政策

> 版本：v0.1（框架稿）｜ 生效日期：上线前另行公布 ｜ 责任角色：产品经理起草，**上线前需法务复核确认**
> 依据：《需求文档》v1.0 第 9 章合规要求；《中华人民共和国个人信息保护法》

## 引言

我们（运营方）重视你的个人信息与隐私。使用 SaaS Starter（下称「本平台」）前，请仔细阅读并充分理解本政策。**你点击同意或实际使用本平台，即表示已理解并同意本政策。**

本政策适用于注册、使用本平台全部功能（含网站、邮件通知、AI 问答）所涉及的个人信息处理活动。

## 1. 我们收集的信息

遵循**最小必要**原则，仅收集实现功能所必需的信息：

| 类别 | 内容 | 来源 | 目的 |
|------|------|------|------|
| 账号信息 | 邮箱地址、密码（bcrypt 哈希后存储，明文不可见）、昵称、头像 | 你主动填写 | 注册、登录、身份验证 |
| 租户与权限信息 | 你所属租户、角色、成员关系 | 你或租户管理者操作 | 多租户数据隔离与权限控制 |
| 业务数据 | 你创建 / 上传的资源、附件、知识库文档 | 你主动提交 | 提供业务功能与 AI 问答 |
| 使用日志 | 访问时间、IP、操作行为、错误日志 | 系统自动记录 | 安全审计、故障排查（不记录明文密码与令牌） |

**我们不收集**：身份证号、生物识别、宗教信仰、行踪轨迹等敏感个人信息；不向用户索取手机号（短信通道为模拟，不真实发送）。

## 2. 信息的使用

- 身份验证、账号与租户管理、权限控制；
- 提供业务数据的存储、展示、检索；
- 提供 AI 问答：将你上传的文档切分、向量化后用于语义检索与回答生成；
- 发送服务性通知（验证、安全提醒、订阅状态）；
- 保障安全：限流、防滥用、审计留痕。

**禁止的用途**：不出售你的个人信息；不用于与你使用目的无关的推荐 / 营销；不将你租户内的数据用于训练任何外部模型。

## 3. 存储地点与跨境告知（重要）

本平台采用的计算与存储服务位于**中华人民共和国境外**（详见第 4 条第三方清单，含 Cloudflare、Neon 等）。**你的个人信息将存储于境外服务器，存在跨境传输。**

依据《个人信息保护法》第 39 条，我们在此**单独、明确告知**该跨境事实；你同意本政策即视为同意该跨境传输安排。若你不接受，请停止注册并关闭页面。

## 4. 委托处理 / 第三方服务清单

我们不自营基础设施，以下第三方受我们委托处理数据（仅用于提供功能，无权挪作他用）：

| 第三方 | 用途 | 处理的数据 |
|--------|------|------------|
| Cloudflare（Pages）/ 腾讯云 COS | 站点分发、文件存储 | 静态资源、上传文件、访问日志 |
| Render / Railway | 后端 API 运行 | 业务数据（处理中） |
| Neon | PostgreSQL 数据库 | 全部业务数据与账号信息 |
| Upstash | 队列 / 缓存 | 异步任务载荷（不含密码明文） |
| LLM API 服务商 | AI 回答生成 | 你提问的内容与检索到的文档片段 |
| 邮件服务商（SMTP / Resend） | 验证与通知邮件 | 邮箱地址、邮件内容 |

我们与上述服务之间通过合同 / 平台协议约束其数据处理行为。**清单变更时我们会更新本政策。**

## 5. Cookie 与本地存储

- 本平台使用 JWT 令牌维持登录态，令牌存储于浏览器本地（登录态与安全所需）；
- 不使用广告 / 跨站追踪类 Cookie；
- 你可随时清除浏览器本地存储以退出登录态。

## 6. 你的权利

你可以通过「个人中心」自助或联系我们行使以下权利：

| 权利 | 行使方式 |
|------|----------|
| 查阅 / 复制（导出） | 个人中心「数据导出」，下载账号数据副本（JSON） |
| 更正 | 个人中心直接修改昵称 / 头像 / 密码 |
| 删除 | 删除业务数据 / 附件；注销账号后按留存策略删除 |
| 撤回同意 | 注销账号即撤回全部处理同意 |
| 注销账号 | 个人中心发起；注销后账号停用，数据按第 7 条处理 |
| 投诉 / 求解释 | 联系第 9 条邮箱 |

**响应时限**：自助操作即时生效；需人工处理的请求，我们在 15 个工作日内响应。

## 7. 留存与删除策略

| 数据 | 留存规则 |
|------|----------|
| 账号与业务数据 | 账号注销后 30 天内删除或匿名化（法律另有要求除外） |
| 上传文件与 AI 知识库 | 随租户数据一并删除 |
| 审计日志 | 保留不超过 180 天（安全审计必需） |
| 备份 | 平台级自动备份不超过 35 天，到期自动轮换删除 |

## 8. 未成年人保护

本平台面向具备完全民事行为能力的专业人士，**不向未满 18 周岁未成年人提供服务**；不主动收集未成年人信息。若发现误收集，我们将立即删除。
