## 1. 产品简介

SaaS Starter 是一套**多租户中后台 SaaS 平台**。注册后你将拥有一个独立的工作空间（租户），在其中管理成员与权限、维护业务数据、上传文件、使用 AI 智能问答，并体验订阅流程。

**核心概念**

| 概念 | 说明 |
|------|------|
| 租户（工作空间） | 数据隔离的基本单位；你的所有业务数据仅在你的租户内可见 |
| 成员 | 被邀请进入同一租户的协作用户，共享该租户的数据 |
| 角色 | owner（所有者）/ admin（管理员）/ member（成员），决定可执行的操作 |

## 2. 首次使用

### 2.1 注册

1. 访问平台首页，点击「注册」。
2. 填写邮箱、设置密码（8 位以上，含字母与数字）。
3. 提交后系统发送验证邮件（查收邮箱，含收件箱 / 垃圾箱提示），点击邮件内链接完成验证。
4. 验证成功即**自动创建你的租户**，你默认成为该租户的 owner。

> 未验证邮箱前不能登录使用核心功能（数据最小化与账号真实性要求）。

### 2.2 登录与找回密码

- 登录：邮箱 + 密码；连续失败多次会被临时限流锁定，稍后重试。
- 找回密码：登录页点「忘记密码」→ 邮箱接收重置链接 → 设置新密码。

### 2.3 成员管理（owner / admin）

1. 进入「设置 → 成员管理」，点击「邀请成员」。
2. 填写对方邮箱与角色（admin / member），系统发送邀请邮件；受邀者注册 / 登录后接受邀请即加入（加入前显示「待激活」状态）。
3. 成员管理操作：
   - **调整角色**：owner / admin 可变更成员角色；
   - **禁用成员**：保留其数据、禁止其登录本租户，可随时恢复；
   - **移除成员**：二次确认后移除出租户；
   - **转让所有权**：owner 可将租户转让给其他成员（二次确认），转让后原 owner 降为 admin。

## 3. 功能模块指南

### 3.1 工作台（首页）

登录后默认进入工作台，展示当前租户概览：成员数、业务数据统计、示例图表、未读通知入口。可通过右上角入口**切换租户**（若你被多个租户邀请）。

### 3.2 示例业务域（工作区资源）

演示用的增删改查模块：

- **新建资源**：填写名称、描述、分类，保存后立即出现在列表。
- **列表操作**：分页浏览、按名称 / 分类过滤、编辑、删除。
- **回收站**：删除的资源进入回收站（并非直接抹除），30 天内可恢复；到期自动彻底删除。回收站仅 owner / admin 可管理。
- **附件上传**：在资源详情中上传文件（头像 / 文档等），文件存储在云端对象存储，通过 URL 访问。演示环境建议单文件 ≤ 10MB。如需上传更大文件（如百 MB 级视频 / 压缩包），系统支持**大文件分片上传（可选增强）**：文件被切片并发直传到对象存储、自动合并，支持断点续传与进度展示——若当前版本未开启该功能，会有明确提示。

> 该模块为演示多租户能力而设，不绑定具体业务；数据按租户严格隔离。

### 3.3 AI 智能问答（RAG）

1. 进入「AI 助手」，上传文档（txt / md / pdf）到租户知识库。
2. 系统后台处理文档（切分、向量化），处理完成后即可提问。
3. 输入问题，AI 基于你的文档流式返回回答，并标注引用来源片段。

**使用须知**

- 回答仅基于你租户内上传的文档，不涉及其他租户数据。
- AI 生成内容存在不准确的可能，请以引用的原文为准。
- 若 AI 服务繁忙或超出用量限制，系统会降级为提示模式，稍后重试。
- **用量额度按套餐限制**（自然月计）：Free 每月 20 次问答，Pro 每月 500 次；超额后当月停用，可在「用量」页查看当前用量与进度。

### 3.4 订阅与支付（模拟）

**套餐与权益**

| 套餐 | 席位 | AI 问答/月 | 存储 | 月价 |
|------|------|------------|------|------|
| Free | 3 | 20 次 | 100MB | ¥0 |
| Pro | 20 | 500 次 | 5GB | ¥29（模拟） |

**操作流程**

1. 进入「订阅」，查看套餐对比与当前用量（席位 / 存储 / AI 次数）。
2. **试用**：每租户可享一次 14 天 Pro 试用，立即获得 Pro 权益；试用到期前会有提醒，到期未转化自动回 Free。
3. **订阅**：选择 Pro → 模拟支付页 → 「模拟支付成功」→ 权益即时生效，并生成账单、发送通知邮件。
4. **账单中心**：查看账单历史（周期、金额、状态）与模拟发票页。
5. **取消 / 退款**：支持期末取消（权益保留至本期结束）与立即取消；订阅期内可申请**全额模拟退款**（二次确认），退款后即时降级 Free。
6. 续费失败时进入 **3 天宽限期**，权益保留，宽限期内重试不会重复扣款（模拟）。

> **当前为模拟支付，不产生任何真实扣款**，仅演示订阅状态机与账务流程（含幂等、对账等资金安全机制）。后续接入真实支付时会在页面显著提示。

### 3.5 消息通知

- **站内通知中心**：铃铛入口，未读计数；订阅成功、邀请、系统公告、安全告警等事件入站，**实时推送无需刷新**（他人修改数据时也会收到「数据已更新」提示条）。
- **邮件通知**：注册验证、密码重置、订阅变更、宽限期提醒发送至绑定邮箱。
- **通知偏好**：个人中心可按类别（订阅 / 成员 / 系统）开关邮件通知；站内通知与安全类告警邮件不可关闭。
- **短信**：当前为模拟通道（仅控制台记录），不会真实发送到手机。

### 3.6 租户设置与审计日志

- **租户设置**（owner / admin）：修改租户名称、上传 Logo、配置品牌主色。
- **审计日志**（owner / admin）：查看租户内敏感操作记录（登录、权限 / 成员变更、数据删除、订阅变更），可按操作人 / 类型 / 时间筛选；日志保留 180 天。

### 3.7 用量看板

「订阅 / 用量」页展示当前套餐下的席位、存储、AI 问答次数的当前值 / 上限 / 百分比；接近上限时给出升级引导。

### 3.8 个人中心与账号管理

- 修改昵称 / 头像、修改密码。
- **数据导出**：下载你的账号数据副本（JSON）。
- **账号注销**：注销后账号停用，租户内数据按留存策略删除（详见《隐私政策》）。

## 4. 界面状态说明（阅读约定）

| 状态 | 表现 | 你需要做的 |
|------|------|------------|
| 加载中 | 列表 / 按钮转圈或骨架屏 | 等待，勿重复点击 |
| 空状态 | 图示 + 文案 + 「新建」引导入口 | 按引导创建第一条数据 |
| 操作失败 | 顶部红色提示，含原因说明 | 按提示修正后重试 |
| 无权限 | 灰色不可用按钮或 403 页 | 联系租户 owner / admin 调整角色 |
| 网络异常 | 全局断网提示条 | 恢复网络后自动重连重试 |

## 5. 常见问题（FAQ）

**Q1：忘记邮箱验证链接在哪里？**
A：检查垃圾邮件文件夹；或登录页重新触发发送（有频率限制，1 次 / 分钟）。

**Q2：为什么看不到其他团队的数据？**
A：平台按租户严格隔离数据，这是 SaaS 的安全基线，属预期行为。

**Q3：AI 回答与文档原文不一致怎么办？**
A：以引用的原文片段为准；可换更明确的提问方式重试。

**Q4：模拟支付会扣钱吗？可以退款吗？**
A：不会扣钱，全程模拟。订阅期内可在订阅页发起全额模拟退款（二次确认），退款后即时降级 Free。

**Q5：上传的文件有大小 / 类型限制吗？**
A：演示环境单文件 ≤ 10MB，支持常见文档与图片格式；另受套餐存储配额限制（Free 100MB / Pro 5GB），超额上传会被拦截并提示升级。若需更大文件，可启用「大文件分片上传（可选增强）」，支持百 MB 级文件切片并发直传、断点续传与进度展示；未开启时超出 10MB 会被拒绝并提示。

**Q6：如何彻底删除我的数据？**
A：个人中心可导出数据后注销账号；注销后数据按《隐私政策》的留存策略处理。
