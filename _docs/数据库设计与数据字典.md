## 1. 设计总则

| 约定 | 内容 |
|------|------|
| 命名 | 表名复数 snake_case（`resources`）；字段 snake_case（`created_at`）；索引 `idx_{表}_{字段}`，唯一 `uk_`，外键 `fk_` |
| 主键 | `id VARCHAR(32) cuid`（分布式友好、URL 安全） |
| 租户隔离 | 除 `users`、`plans`、`payment_idempotency`（键含租户维度）等平台级表外，**所有业务表强制含 `tenant_id`** + 索引；查询经 Prisma Extension 自动注入过滤 |
| 时间戳 | 全部 `TIMESTAMP(3) UTC`；`created_at` / `updated_at` 必备 |
| 软删除 | 仅资源域使用：`deleted_at NULL`（NULL=未删）；回收站 30 天 |
| 金额 | **Integer 分**（`*_cents`），全链路无浮点 |
| 枚举 | Postgres 原生 ENUM 类型，取值与 shared 包 TS 常量同源 |
| 向量 | `ai_chunks.embedding vector(1536)`，pgvector 扩展 |
| 外键 | 物理外键 `ON DELETE` 明确标注；跨域仅引用 id 不做级联（防误删扩散） |

## 3. 分域表设计

### 3.1 身份与租户域

#### users（平台级：同一邮箱一个账号，可属多租户）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | VARCHAR(32) | PK | cuid |
| email | VARCHAR(255) | UNIQUE, NOT NULL | 登录凭证，小写化存储 |
| password_hash | VARCHAR(100) | NOT NULL | bcrypt cost ≥ 12 |
| nickname | VARCHAR(50) | NOT NULL | 默认取邮箱前缀 |
| avatar_url | VARCHAR(500) | NULL | R2 公开 URL（走 files 上传） |
| email_verified_at | TIMESTAMP | NULL | NULL = 未验证，未验证不可登录 |
| last_login_at | TIMESTAMP | NULL | 审计/展示 |
| status | user_status | NOT NULL DEFAULT 'active' | active / deleted（注销软停用） |
| created_at / updated_at | TIMESTAMP | NOT NULL | — |

#### tenants

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | VARCHAR(32) | PK | cuid |
| name | VARCHAR(100) | NOT NULL | 注册时生成，可改 |
| logo_url | VARCHAR(500) | NULL | 品牌化 |
| brand_color | VARCHAR(9) | NULL | HEX，如 #1677FF |
| owner_id | VARCHAR(32) | FK→users.id, NOT NULL | 冗余当前 owner（与 memberships 联合校验），转让时事务内同步 |
| deleted_at | TIMESTAMP | NULL | 注销连带软删（演示级保留） |
| created_at / updated_at | TIMESTAMP | NOT NULL | — |

> 索引：`idx_tenants_owner_id`

#### memberships（用户-租户多对多 + 角色 + 生命周期状态）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | VARCHAR(32) | PK | — |
| tenant_id | VARCHAR(32) | FK→tenants.id, NOT NULL | 级联删 |
| user_id | VARCHAR(32) | FK→users.id, NOT NULL | 级联删 |
| role | member_role | NOT NULL | owner / admin / member |
| status | member_status | NOT NULL DEFAULT 'active' | active / disabled / removed（保留行供留痕，removed 不再出现在成员列表） |
| invited_by | VARCHAR(32) | NULL | 邀请人 user_id（注册自建为 NULL） |
| joined_at | TIMESTAMP | NOT NULL | — |
| last_active_at | TIMESTAMP | NULL | presence 降级：认证中间件节流更新 |
| created_at / updated_at | TIMESTAMP | NOT NULL | — |

> 约束：`uk_memberships_tenant_user UNIQUE(tenant_id, user_id)`；业务约束（应用层）：每租户至多一个 owner 行；`idx_memberships_user_id`（跨租户列表查询）。

#### invitations（待激活成员）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | VARCHAR(32) | PK | — |
| tenant_id | VARCHAR(32) | FK, NOT NULL | — |
| email | VARCHAR(255) | NOT NULL | 受邀邮箱 |
| role | member_role | NOT NULL | 仅允许 admin / member |
| token | VARCHAR(64) | UNIQUE NOT NULL | 邀请链接令牌 |
| invited_by | VARCHAR(32) | NOT NULL | — |
| status | invitation_status | NOT NULL DEFAULT 'pending' | pending / accepted / expired / revoked |
| expires_at | TIMESTAMP | NOT NULL | 发出后 7 天 |
| created_at / updated_at | TIMESTAMP | NOT NULL | — |

> `uk_invitations_tenant_email_status` 用应用层实现（pending 唯一）。

#### email_tokens（验证 / 重置令牌）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | VARCHAR(32) | PK | — |
| user_id | VARCHAR(32) | FK→users.id, NOT NULL | — |
| type | email_token_type | NOT NULL | verify_email / reset_password |
| token_hash | VARCHAR(64) | NOT NULL | SHA-256(令牌)，原文只出现在邮件链接 |
| expires_at | TIMESTAMP | NOT NULL | verify 15min / reset 30min |
| used_at | TIMESTAMP | NULL | 单次有效 |
| created_at | TIMESTAMP | NOT NULL | cleanup 队列清理过期 |

> `idx_email_tokens_token_hash`

#### refresh_tokens（可吊销会话）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | VARCHAR(32) | PK | — |
| user_id | VARCHAR(32) | FK→users.id, NOT NULL | — |

### 3.2 业务域

#### resources（示例业务域：工作区资源）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | VARCHAR(32) | PK | — |
| tenant_id | VARCHAR(32) | FK, NOT NULL | 隔离键 |
| name | VARCHAR(100) | NOT NULL | — |
| description | TEXT | NULL | — |
| category | VARCHAR(50) | NULL | 过滤维度 |
| created_by | VARCHAR(32) | FK→users.id, NOT NULL | — |
| deleted_at | TIMESTAMP | NULL | 软删除标记；NULL=正常 |
| purged_at | TIMESTAMP | NULL | 物理删除时间（清理任务回填后删行） |
| created_at / updated_at | TIMESTAMP | NOT NULL | — |

> 索引：`idx_resources_tenant_deleted (tenant_id, deleted_at)`——正常列表与回收站共用；`idx_resources_tenant_category (tenant_id, category)`。
> 恢复窗口：`deleted_at + 30d`，cleanup 队列每日扫描物理删除并连带 R2 附件。

#### files（上传文件元数据）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | VARCHAR(32) | PK | — |
| tenant_id | VARCHAR(32) | FK, NOT NULL | — |
| resource_id | VARCHAR(32) | FK→resources.id, NULL ON DELETE SET NULL | 附件归属资源；头像等独立文件为 NULL |
| uploaded_by | VARCHAR(32) | NOT NULL | — |
| object_key | VARCHAR(300) | NOT NULL | R2 对象键（含租户前缀 `t/{tenantId}/...`） |
| url | VARCHAR(500) | NOT NULL | 访问 URL |
| original_name | VARCHAR(200) | NOT NULL | 原文件名（展示） |
| mime_type | VARCHAR(100) | NOT NULL | 类型白名单校验依据 |
| size_bytes | BIGINT | NOT NULL | 存储配额统计口径来源（含软删除未到期） |
| deleted_at | TIMESTAMP | NULL | 跟随资源软删；物理删时清理 R2 |
| created_at | TIMESTAMP | NOT NULL | — |

> `idx_files_tenant_deleted (tenant_id, deleted_at)`；配额统计：`SUM(size_bytes) WHERE tenant_id=? AND (deleted_at IS NULL OR deleted_at > now()-30d)`。

|------|------|------|------|

## 4. 枚举字典

| ENUM 类型 | 取值 | 用途 |
|-----------|------|------|

## 7. Prisma 映射与迁移策略

- **映射约定**：Prisma model 用 PascalCase + `@map`/`@@map` 映射 snake_case 表字段（工程规范）；migration 只增不改历史；本地 `migrate dev`、生产 `migrate deploy`（CI 执行）。
- **pgvector**：Prisma 原生不支持 vector 类型，`embedding` 声明为 `Unsupported("vector(1536)")` + migration 内手写 `CREATE EXTENSION IF NOT EXISTS vector`、索引 SQL；读写用 `$queryRaw`（参数化）。
- **seed**：`prisma/seed.ts` 造 2 租户 ×（owner+admin+member）× 若干资源/账单/通知，含一条 past_due 示例与一条对账差异，覆盖演示全路径。
- **B 方案（schema 隔离）迁移路径**：不实施；预留点为按 tenantId 导出脚本 + multiSchema 配置，见 TSD §5.4。
